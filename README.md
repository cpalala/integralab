Jalankan lokal: `pip install -r requirements.txt` lalu `python -m streamlit run app.py`

Deploy (Streamlit Community Cloud):
1. Upload folder ini ke repositori GitHub (publik).
2. Buka share.streamlit.io, login dengan GitHub, klik "Create app".
3. Pilih repositori dan branch, isi Main file path: `app.py`, lalu Deploy.
